# SherSher
Offline share-share bill splitter for Android + iOS (Flutter). One-time PHP 199 unlock.

    flutter pub get
    dart test

Start with SETUP_ANTIGRAVITY.md, then paste KICKOFF_PROMPT.md into the agent.

## Folder map
- `AGENTS.md`, `GEMINI.md`, `CLAUDE.md` — build rules for the coding agent (same content)
- `KICKOFF_PROMPT.md` — first message to give the agent
- `docs/` — PRODUCT_SPEC.md, DESIGN.md
- `design/screens/` — 19 prototype screens; `design/canvas.json` layout
- `lib/domain/` — split engine (done, tested)
- `lib/data/` — database (to build)
- `lib/ui/` — screens (to build)
- `test/domain/` — engine tests
- `assets/` — fonts, images
- `.agents/mcp_config.json` — Dart MCP server
